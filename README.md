# Sola Video Download Manager

## 🇺🇸 English

### 📖 About

**Sola Video Download Manager** is a powerful desktop application that allows you to download videos from multiple platforms including YouTube, TikTok, Facebook, Instagram, and 1000+ websites.

### ✨ Features

- 🚀 **High-Speed Downloads** - Multi-threaded downloading for maximum speed
- 📺 **Multi-Platform Support** - YouTube, TikTok, Facebook, Instagram, Twitter, and more
- 🎨 **Modern UI** - Beautiful dark/light theme interface
- 📋 **Batch Download** - Download multiple videos at once
- 🎵 **Quality Selection** - Choose from 4K, 1080p, 720p, 480p, 360p
- 📁 **Custom Output** - Flexible file naming and output folder options
- 🔄 **Auto-Update** - Automatic update notifications
- 🌐 **Multi-Language** - English and Vietnamese support

### 💻 System Requirements

| Requirement | Minimum |
|-------------|---------|
| **OS** | Windows 10/11 (64-bit) | Linux (64-bit) | Osx (64-bit)
| **RAM** | 4 GB |
| **Storage** | 150 MB free space |
| **Internet** | Required for downloads |


### 🚀 Quick Start

1. Launch **SolaDownload.exe**
2. Paste video URL(s) into the input field
3. Select quality and format
4. Click **Start Download**
5. Find your videos in the output folder
